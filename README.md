# Gestor Weslen — Nova landing page

Landing page dos planos **Plano Escala** (3 marketplaces) e **Gestão Completa** (6 marketplaces), com tráfego pago integrado.

## Estrutura

- `index.html` — página completa (HTML + CSS + JS das abas e do FAQ, tudo em um arquivo)
- `assets/logo-gold.png` — logotipo em dourado com fundo transparente

Site estático: basta subir os arquivos para qualquer hospedagem.

## Fontes

Google Fonts: Bricolage Grotesque (títulos), Hanken Grotesk (texto) e Mrs Saint Delafield (assinatura).

## Animações

- Entrada do hero e loops (ilustração, marquees, brilhos) em CSS puro.
- Animações de scroll com CSS scroll-driven animations (`animation-timeline`). Funcionam em Chrome, Edge e Safari recentes; nos outros navegadores o conteúdo aparece normalmente, sem o efeito.
- `prefers-reduced-motion` desativa todas as animações.

## Pendências (aguardando o cliente)

- FAQ: preço, prazo, fidelidade, investimento em anúncios e CNPJ estão em lorem ipsum.
- Logos das lojas parceiras e prints de depoimentos são placeholders.
- Foto do Weslen (seção Sobre) é placeholder.
